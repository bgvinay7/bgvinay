# Vinay BG — Backend Engineering Portfolio

A responsive, static portfolio website for **Vinay BG**, Senior Java Backend Engineer / Module Lead with 11+ years of experience.

## Website sections

- Professional introduction and career highlights
- Backend, distributed systems, database, cloud, and leadership skills
- Four generalized case studies with measurable outcomes
- Professional experience timeline
- Education and certification
- Email and LinkedIn contact links

## Run locally

No build tools are required.

1. Download or clone this repository.
2. Open `index.html` in a browser.

For a local development server, you can use the VS Code **Live Server** extension.

## Publish with GitHub Pages

1. Create a GitHub repository named `YOUR-USERNAME.github.io` (replace with your actual GitHub username).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)` folder, then save.
6. After GitHub Pages finishes deploying, your site will be available at `https://YOUR-USERNAME.github.io/`.

You can also use a regular repository name and enable Pages in its settings; the URL will then include the repository name.

## Personalize before publishing

- Confirm the email and LinkedIn URL in `index.html`.
- Replace the LinkedIn URL if your preferred profile URL differs.
- Add your GitHub profile URL after confirming your username.
- Optionally add links to public repositories or demos for projects you can share.
- Review all career dates and project metrics against your final resume.
- Keep confidential employer/client names, source code, internal URLs, and sensitive architecture details out of public case studies.

## Project case studies

The case studies are intentionally high-level summaries of professional work, not claims that the original employer systems are open-source projects. If you want to demonstrate implementation skills publicly, create separate sample repositories with synthetic data and original code.
